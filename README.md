# sistema-clm-noa

Sistema de Gestión de Medicina Laboral — Centro Médico Laboral del NOA S.R.L. (Escencial Consultora). Incremento 1: Prelaboral.

- `Docs/` — Requerimientos funcionales (27 RF), ficha técnica no funcional (30 RNF) y arquitectura de despliegue, cotización real de estudios.
- `maqueta-react/` — Maqueta de UX en React + Tailwind (prototipo de validación de pantallas; el build final de producción va en Angular + Node/Express + PostgreSQL sobre servidor local, según la ficha técnica ya cerrada con el cliente).

Contexto completo del proyecto en `cerebro-facundo/proyectos/kaplan-cml-noa/`.
